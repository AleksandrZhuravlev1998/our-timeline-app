# Our Timeline — web app

A small, self-contained relationship-timeline app. This **public** repo holds only the
app shell (HTML/CSS/JS, fonts, jsPDF) served via GitHub Pages — **no personal data**.

The actual moments live in a separate **private** repo (`our-timeline-data`) and are only
read/written with a personal access token entered in the app's ⚙ settings.

➡️ Setup instructions: **[SETUP.md](SETUP.md)**

- Pages serves from `/docs`.
- Photos + text sync through GitHub; videos stay local to the phone app.
- Works offline; syncs when online.
